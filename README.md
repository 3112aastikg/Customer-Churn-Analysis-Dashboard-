# 📊 Customer Churn Analysis Dashboard | Tableau

An interactive Tableau dashboard built to analyze customer churn, identify key churn drivers, and understand high-risk customer segments.

## 📌 Project Overview

The dashboard focuses on:
- Churn Overview
- Customer Churn Drivers
- Customer Segmentation

This dashboard provides insights into:
- Overall customer churn and retention
- Churn by subscription type and contract length
- Customer churn drivers such as age, tenure, support calls, usage frequency, payment delay, and last interaction
- Customer segmentation by gender, subscription type, contract length, and total spend

## 📈 Key Metrics

- **Total Customers:** 440,832
- **Churned Customers:** 249,999
- **Retained Customers:** 190,833
- **Overall Churn Rate:** 56.71%
- **Average Total Spend:** 547
